# WhoIsEntered
WhoIsEntered - Automatically System, which save to send on your server ScreenShot from your WEB Cam.

DON'T USE FOR ILLEGAL. Use for yourself safety. Work in Notebook.

1. GIT CLONE

First step's a git clone repository in your directory

How in here with terminal:
```bash
git clone git@github.com:Godlakes/WhoIsEntered.git
```

2. SETUP ON YOUR PC
Open in your terminal your directory repository, and launch install.sh:
```bash
cd WhoIsEntered
chmod +x install.sh
./install.sh
```

Recommended choose a second variant (SYSTEMD) such as very stability.


3. FINISH
Default saving photo on localhost at the path:
~/.cam/photos/

Check this repository.

Make sure you have SSH key-based access to the remote server, that root login is disabled, and that password authentication is prohibited.
